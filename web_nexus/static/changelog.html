What's new in Nexus

A live record of every shipped change — features, fixes, and behind-the-scenes work. For the full git history, see github.com/Thyfwx/nexus.

v5.6.9 SECURITY 2026-05-30
A security hardening pass across the terminal and the backend, plus a fix so the boot line always shows the version that is actually deployed. No feature changes: the terminal looks and works the same, it is just harder to abuse and honest about its version.
— PATCHES
  • Terminal output is locked down: AI replies and anything you type always render as plain text, never as live markup. Untrusted content can no longer inject code into the page.
  • The AI is hardened against prompt injection. It treats all input and prior history as untrusted, refuses to reveal or change its own instructions, and ignores attempts to switch its rules or mode.
  • Leaderboards now validate scores and cap how often they can be submitted, so the boards can no longer be flooded or stuffed with impossible numbers.
  • Added rate limiting across chat and the report endpoints so no single source can hammer the service.
  • The boot line reads the live deployed version straight from the backend, so it never lags behind the real version again.
v5.6.8 HOTFIX 2026-05-22
Worker /api/summarize now retries on Gemini free-tier 503s and falls back to gemini-2.5-flash-lite if the primary model stays unavailable. Verified end-to-end on the Gemini 2.5 blog post: 64-word summary returned in 8 seconds with no chatty opener and no empty title quotes.
— PATCHES
  • /api/summarize wraps the Gemini call in a retry chain: 1 retry with 1 second backoff on 503/429, then fall back to gemini-2.5-flash-lite (also free tier). The free Gemini 2.5 Flash endpoint frequently returns 503 UNAVAILABLE under load; lite has lower latency and is rarely throttled.
  • Clearer error to users when both models are exhausted: "Summary service is busy. Try again in a minute." instead of "No summary returned."
v5.6.7 HOTFIX 2026-05-22
v5.6.6 shipped with the TL;DR summarize button still broken. The fix needed one more piece: Gemini 2.5 Flash has dynamic thinking enabled by default, which eats the maxOutputTokens budget before any visible text comes out. Set thinkingBudget to 0 to disable thinking for summarize calls (no chain-of-thought needed for a 5-sentence summary), bumped maxOutputTokens to 512 as safety margin.
— PATCHES
  • Worker /api/summarize now passes thinkingConfig.thinkingBudget=0 to Gemini 2.5 Flash so the model spends tokens on actual output, not on internal reasoning. Summaries now return the full 4 to 5 sentences instead of cutting off after one fragment.
v5.6.6 PATCHES 2026-05-22
TL;DR summarize button no longer outputs "okay, so this post is called ...". Daily cap on portfolio summaries lifted from 30 to 100 per IP now that Gemini 2.5 Flash runs on the free tier.
— PATCHES
  • TL;DR button output cleaned up. Frontend now extracts the H1 (or document.title) and sends it to the Worker as a dedicated title field. Worker prompt rewritten with hard rules forbidding conversational openers ("okay", "so", "alright", "basically", "well") and the "this post is called ..." pattern. Cache key now includes the title so different pages with similar bodies do not collide.
  • Daily summarize cap lifted from 30 to 100 requests per IP per day. Cache hits still cost zero. Free Gemini 2.5 Flash quota is comfortable at this rate.
  • JSON-LD blocks, <nav>, <header>, and <footer> now stripped from the page content before sending to the model. The 8K input budget goes to actual article text instead of structured metadata.
